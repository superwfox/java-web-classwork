# DB-IP Country Lite

Source: https://db-ip.com/db/download/ip-to-country-lite
Publisher: DB-IP / Eris Networks S.A.S
Snapshot: September 2026, downloaded 2026-09-28.
File: dbip-country-lite.csv.gz (original compressed CSV, unmodified).
License: Creative Commons Attribution 4.0 International (CC BY 4.0).
License text: https://creativecommons.org/licenses/by/4.0/legalcode

The application imports the CSV IP ranges into SQLite for local lookup.
Geolocation is approximate; Lite has reduced coverage and accuracy.
The footer includes the required "IP Geolocation by DB-IP" attribution link.
A replacement snapshot can be supplied with JAVA_WEB_GEO_FILE (CSV.GZ).
